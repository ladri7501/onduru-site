About

For more than 20 years I have analyzed and designed core business systems for the public sector, the judiciary, finance, and large enterprises. When several organizations handle the same work by different criteria, my strength is to define collection items and aggregation rules that business users and developers can both work with, and to carry them into the database and the screens.

Most recently I led the analysis and design of an HR analytics platform for a large corporate group. I made it possible to aggregate each affiliate’s HR data by a common group standard, to see the workforce of the whole group, and to compare hiring, attrition, and labor cost across business divisions on the same basis. When a question comes up about a figure in a report, the indicator definition document and the screen-by-screen mapping table make it possible to check which data items and which indicator definition were applied.

The role I want is to set business and data criteria clearly and turn them into a structure that the people doing the work can trust and use.

Featured Project

Integrated HR analytics platform for a large corporate group | Analysis and design lead

40 statistical reports (6 of them on labor cost) · worked with two developers

Explore the HR Insight portfolio · interactive demo in Korean →

  • Comparing current and former employee figures across affiliates — I unified the HR data collection items, which had differed from affiliate to affiliate. The common HR items are collected on the same form for current and former employees, and the type, reason, and date of leaving are added for former employees. On that basis, each affiliate’s current and former employee figures can be aggregated consistently.
  • Checking how a statistical figure was produced — I preserved each affiliate’s source values and recorded which group standard code each source code corresponds to. When a particular report is reviewed, the screen-by-screen mapping table shows the indicators and data items it uses, and the indicator definition document gives the meaning of each indicator.
  • Group-wide and division-level statistics — I designed a FACT/DIM data mart and worked with the developers to apply the common aggregation rules to the query API and the dashboard. Headcount, hiring, attrition, promotion, length of service, and labor cost can be viewed for the whole group and compared across business divisions.
  • I implemented the query screens and the batch processing myself.
