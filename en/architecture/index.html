How to Read

No done / to-do split. The whole of ONDURU is drawn as present fact, and every node and link carries a verb. Nothing unfinished is written as finished; the verb makes that distinction.

Verbs: five words that set the outline of every node and line

  • Operating In use now, with a continuing record
  • Tested Actually run, with a record
  • Building Part of it exists; the rest is being built
  • Reviewed Design reviewed by another eye, verdict recorded; not yet run
  • Designed Decided in writing; no run record found

Lines: what moves, and which way

  • Flow Passes in the direction of the arrow
  • One way Built in one direction only; nothing flows back
  • Port A part is swapped through the same port
  • Block Blocked: this path is closed

Money: where it is spent and where it is not

  • Subscription Subscription and credits: work stops when the limit is reached
  • Electricity Electricity: watts × hours × rate; the rate is not confirmed
  • Prepaid, capped Prepaid with a cap: automatic top-up is off
  • No token cost No token cost: it runs on On’s own machines, on electricity alone
  • No server No server: static files
  • Owned device A device On already owns; no record of the purchase price
  • Human time The person’s time
  • No data No data

Introduction

This diagram shows a workplace that one person is building. What a large organization secures with staff and budget (permissions, audit records, test environments, cost control) On provides with files, On’s own machines, and rented Agents. On calls it the One-Person David Platform.

There are two ways to read it. From top to bottom it is a set of bands: People, Territory, Border, Outside. And every node carries a verb: Operating, Tested, Building, Reviewed, Designed. The style of each line follows its verb too. Nothing unfinished is drawn as if it were finished.

One round of a single piece of work is arranged like this. On hands intent and scope to a seat. The seat calls the models: small models do the first shaping, and the large model gives its judgment only once. The work is tried out with made-up data in a sandbox, a disposable space kept apart from production. An eye other than the maker’s looks at the result. Only what cannot be undone comes up to On, and On approves it. Every handoff leaves a record.

Those records are the center of the diagram. The material is not a scatter of files; it is a knowledge information system that can be traced back. The originals are text files on On’s own machine, every file gets a fingerprint, and each document states its lineage at the top. The ledger that a person can read is the authoritative copy, and the graph and the vector store are built from it in one direction only. Retrieval tools such as RAG, CAG and MAG are parts on the Agent side that work on top of it. Tools may change; the ledger stays.

Money goes to the subscription for outside Agents and to electricity, and to the devices and the domain On already has. Reading, chunking, summarizing and checking are done by code and by the models on On’s own machines, so they cost no tokens, and the public site runs without a server. The mechanism that writes spending into the ledger has been designed; for that reason no figure for money saved is written down yet.

Everything written in the diagram is a present fact. Fingerprint matching and handoff notes are in use now. The models on On’s own machines and the checks at the outbound gate have been run and measured. The tiers and ports of the store have been reviewed. The sandbox and the enforcement devices on the mini PC have been designed and are next to be installed. The inspector’s seat is empty. The diagram keeps those distinctions as they are.
