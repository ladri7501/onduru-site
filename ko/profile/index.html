소개

공공 · 사법 · 금융 · 대기업의 핵심 업무 시스템을 20년 넘게 분석하고 설계해 왔습니다. 여러 조직이 같은 업무를 서로 다른 기준으로 처리할 때, 현업과 개발자가 함께 쓸 수 있는 수집 항목과 집계 규칙을 정하고 이를 데이터베이스와 화면에 반영하는 것이 제 강점입니다.

최근에는 대기업 그룹 HR 분석 플랫폼의 분석 · 설계를 이끌었습니다. 계열사별 인사 자료를 그룹 공통 기준으로 집계해 그룹 전체의 인력 현황을 파악하고, 업군별 채용 · 퇴사 · 인건비를 같은 기준으로 비교할 수 있게 했습니다. 장표의 수치에 질문이 생기면 지표 정의서와 화면별 매핑표로 어떤 데이터 항목과 지표 정의를 적용했는지 확인할 수 있게 했습니다.

업무와 데이터 기준을 명확히 세우고, 현업이 신뢰하고 쓸 수 있는 구조로 만드는 역할을 하고 싶습니다.

대표 프로젝트

대기업 그룹 통합 HR 분석 플랫폼 | 분석 · 설계 리드

통계 장표 40개(인건비 6종 포함) · 개발자 2명과 협업

  • 계열사 간 재직 · 퇴직 현황 비교 — 계열사마다 달랐던 인사 자료의 수집 항목을 통일했습니다. 재직자와 퇴직자는 공통 인사 항목을 같은 양식으로 수집하고, 퇴직자에게는 퇴직 구분 · 사유 · 일자를 추가했습니다. 이를 바탕으로 계열사별 재직 · 퇴직 현황을 일관되게 집계할 수 있게 했습니다.
  • 통계 수치의 산출 근거 확인 — 계열사의 원천값을 보존하고 각 원천 코드가 어떤 그룹 표준 코드에 대응하는지 기록했습니다. 특정 장표를 검토할 때는 화면별 매핑표에서 사용한 지표와 데이터 항목을 찾고, 지표 정의서에서 해당 지표의 의미를 확인할 수 있게 했습니다.
  • 그룹 전체와 업군별 통계 조회 — FACT/DIM 기반 데이터마트를 설계하고, 개발자와 협업해 조회 API와 대시보드에 공통 집계 규칙을 반영했습니다. 그룹 전체의 인원 · 채용 · 퇴사 · 승진 · 근속 · 인건비 현황을 조회하고 업군별 차이를 비교할 수 있게 했습니다.
  • 조회 화면과 배치 처리는 직접 구현했습니다.

주요 경력

  • 공공 복지 · 정책지원 — 공공 사회복지 통합정보시스템과 중소기업 정책지원 시스템에서 행정 업무를 분석하고 대외기관 데이터 연계를 설계 · 개발했습니다.
  • 사법 · 기업 법무 — 전자소송 민사신청과 대기업 글로벌 법무 시스템에서 신청 · 송무 절차를 분석하고 화면 · 프로그램 · 데이터베이스를 설계했습니다. 법무 시스템에서는 계약 신청과 송무 절차에 더해, 법리 검토를 돕는 사법 시스템 연계와 사내 시스템 정보 연계를 수행했고, 신용평가사 정보를 연계한 건설사 리스크 관리를 분석 · 설계했습니다.
  • 은행 HR · 금융 마이데이터 — 시중은행 HR 시스템에서 인사통계 처리를 구현하고, 저축은행 마이데이터 사업에서 금융 데이터 표준 인터페이스를 구축했습니다.
  • ERP · 경영관리 — 재무 · 자금 · 정산 · 인사 · 연구 · 품질 · 구매 업무를 분석하고, MIS 시스템을 ERP 시스템으로 전환하는 작업을 수행했으며, 비용 이상 점검과 분양관리 시스템을 구현했습니다.

AI 활용 경험

기업 보안 환경의 권한 · 토큰 제약 안에서 M365 Copilot을 설계 문서 정리에, GitHub Copilot을 화면 · 배치 개발에 활용했습니다. 작업 전에 설계 기준과 참조 문서를 지정하고, 생성된 결과물의 검토 담당자와 반영 시점을 팀이 확인할 수 있도록 작업 절차를 문서화했습니다.

기술

  • 업무 분석 · 설계 — 요구사항 분석, 업무 프로세스 설계, HR 지표 정의, FACT/DIM 데이터 모델링
  • 애플리케이션 · 연계 — Java, Spring Boot, MyBatis, REST API, 배치 처리, React, AG Grid
  • 데이터 — Oracle, PostgreSQL, SQL, 데이터마트 설계, 원천 코드와 표준 코드 매핑
  • AI 활용 — 권한 · 자원 · 역할이 제한된 기업의 Microsoft 환경에서 자료를 정제하고, M365 Copilot(에이전트 · Notebooks)과 GitHub Copilot을 이어 쓰는 공정을 만들어 설계 · 개발 · 테스트 · 배포 작업의 자동화에 적용했습니다.
  • 개인 연구 — ONDURU 방법론을 검증하기 위해 Qwen · Ollama · llama.cpp를 활용해 로컬 언어 모델을 구동하고, Claude · ChatGPT · Gemini · Grok과 연결한 다자간 에이전트 환경을 구축하며 시뮬레이션 실험을 진행하고 있습니다.
